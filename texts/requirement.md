## スライドショー CSS仕様

3枚の場合（周期25秒）:

```css
@keyframes slideshow {
  0%, 29% { opacity: 1; }
  33%, 96% { opacity: 0; }
  100% { opacity: 1; }
}
```

| 枚数 | キーフレーム（表示終 / フェード終） | delay間隔 |

## 技術仕様メモ

- **フォーマット**: bundled HTML（`sample1/index.html`）。`<script type="__bundler/template">` 内にJSON文字列でテンプレートHTMLを格納。
- **レンダリング**: `<x-dc>` カスタム要素（React）。`DCLogic` クラスが1秒ごとにカウントダウンを更新。
- **テンプレート変数**: `{{days}}`, `{{timeUnits}}`, `{{timeline}}`, `{{showCountdown}}`, `{{showMap}}` など
- **RSVPバリデーション**: `document.addEventListener('submit', handler, true)` のキャプチャフェーズで実装（Reactの再レンダリング対策）。
- **最大幅**: 480px（スマホ縦向き最適化）
